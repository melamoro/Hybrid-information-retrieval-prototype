# Hybrid-information-retrieval-prototype
Проектное задание выполненное по итогам прохождения интенсива по созданию RAG.  RAG-сервис с FAISS, BM25, Qdrant, CrossEncoder и несколькими retrieval-стратегиями.


запуск: streamlit run main.py -- --strategy_type 1
или streamlit run main.py -- --strategy_type 2
